# 🌤️ Weather Application

A simple web-based weather application that allows users to search for a location and retrieve its current weather information.

---

## 🌍 Overview

The application provides a straightforward interface for checking weather conditions for a selected location.

The project focuses on building a frontend application that can accept user input, request weather data, and present the result in an easy-to-read format.

---

```text
┌──────────────────┐

         ↓
┌──────────────────┐

         ↓
